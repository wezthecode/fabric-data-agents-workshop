# Your Semantic Model Already Did the Work

**Building and shipping Microsoft Fabric data agents.** A three-hour guided build, first run at AIERP Summit Lisbon (27 Nov 2026).

A well-built semantic model is most of the work of a good data agent. This workshop proves it on purpose: you load a synthetic ERP dataset with three planted traps, watch a data agent get questions wrong, fix them in the right place (and see that the obvious place doesn't work), then expose the agent through Copilot Studio.

## How to use this repo

- **In the room:** follow along module by module. Each module ends with a **checkpoint**, so if you fall behind you can catch up at the next one.
- **Afterwards:** run the whole thing at your own pace. Everything you need is here.
- **No paid capacity?** Follow the semantic model steps (modules 0–2 work in Power BI too), then watch the agent parts and repeat them later.

## Before you start

| You need | Why |
|---|---|
| A Fabric workspace on a **paid capacity**: F2 or higher, or Power BI Premium P1+ with Fabric enabled | Data agents don't run on trial capacity. A pay-as-you-go F2 can be paused when you're not using it |
| The **Fabric data agent** tenant setting on, plus **cross-geo processing and storing for AI** if your capacity is outside the US/EU | Without them, data agents don't answer. Ask your admin a few days before |
| Contributor (or higher) on the workspace | To create a lakehouse, warehouse, semantic model and agents |
| For module 5 only: Copilot Studio access, and a Microsoft 365 Copilot licence or Copilot Credits | The Copilot Studio part. It's a live demo in the room |

## The dataset

[dataset/](dataset/) holds **Contoso Cycle Supply**, a made-up bike distributor: 400 customers, 198 items, 20,183 sales orders, 70,651 order lines and 19,898 invoices from January 2024 to 20 November 2026. It's generated by [`dataset/generate.py`](dataset/generate.py) (standard library only, fixed seed), which also writes the correct answers to the test questions in [`dataset/expected-answers.md`](dataset/expected-answers.md).

The traps:

1. **Ambiguous names:** `Status` is on three tables, and `Amount` is net on order lines but gross (incl. 23% VAT) on invoices.
2. **A business definition:** *overdue* means an open balance more than **5 days** past the due date.
3. **A relationship hop:** bike revenue by customer segment needs Customer → Order → Line → Item.

## Facts checked on Microsoft Learn (Nov 2026)

- For semantic models, the data agent's DAX generation uses the model's metadata and **Prep for AI** only. **Instructions added at the data-agent level are ignored for DAX.** Module 4 is built on this.
- **Build agent with AI** (preview) works with SQL and Eventhouse sources only, so module 3 uses a warehouse for it.
- Prep for AI needs **Q&A** turned on for the model, and Microsoft says Q&A experiences are going away in **February 2027**. Watch this space.
- Preview features move. If a step doesn't match what you see, open an issue.

Data is synthetic. Any resemblance to a real company is a coincidence.
